# RING QUEEN — 여자 프로레슬링 매니저

### ▶ [지금 플레이하기](https://rockyhong-a11y.github.io/wwee/)

아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 전체화면 앱처럼 실행됩니다.

---

단일 HTML 파일 웹앱. 의존성·빌드·네트워크 요청 없음. `index.html`을 브라우저로 열면 바로 실행됩니다.
세로 화면 전용(아이폰 최적화, 권장 폭 390~430px). 레트로 도트 UI + 일러스트 캐릭터 아트.

## 핵심 설계

- **커리어 모드**: 선수 1명(여성)의 데뷔 → GWF NEXT → 메인로스터 → 월드 챔피언 여정.
- **FM식 성장**: 능력치 6종 1~20 + **잠재치(PA) 상한**. 주 단위 훈련 XP 누적, 나이·컨디션에 따라 효율 변동, 31세부터 피지컬 노쇠.
- **조작 없음**: 경기는 자동 시뮬레이션 + 텍스트 로그. 플레이어 입력은 주간 활동 선택과 대립 세그먼트 선택뿐.
- **승패는 부커가 정한다**: 승패는 능력치가 아니라 푸시(인지도·신뢰·위상)로 결정되고, 능력치/컨디션은 **경기 평점(★)** 을 결정한다. 평점 → 인지도·신뢰 상승 → 푸시 상승 → 타이틀전. 이것이 게임의 메인 루프.

## 경기 연출

경기는 3페이즈(탐색 → 기술 공방 → 니어폴 공방 → 피니시)로 전개되며, 페이즈마다 다른 문장 풀을 쓴다.

- **하이라이트 모먼트**: 니어폴(2.9 킥아웃) · 카운터 · 하이리스크(탑로프, 실패 가능) · 장외 난투 · 관중 챈트
- **하이라이트가 평점을 만든다**: 발생률 = 양 선수 기량 + 컨디션 + 대립 열기 + PPV 보정. 발생 횟수가 그대로 ★에 반영되므로 로그와 평점이 일치한다
- **난입(run-in)**: 대립 상대가 심판 뒤에서 가격(승률 급락) 하거나, 타이틀전에 제3자가 난입해 **노 콘테스트**(무효, 전적 미기록)가 된다. 난입은 평점을 깎지만 대립 열기를 크게 올리고 새 대립을 만들기도 한다
- **연출**: 비트 종류별 색상·템포(니어폴 950ms, 기본 540ms)와 링 흔들림/적색 플래시. 언제든 빨리감기 가능
- 결과 화면에 하이라이트 내역(니어폴/카운터/하이리스크/장외 횟수)이 집계된다

## 표정(무드) 연출

캐릭터 일러스트는 1장이지만, **시퀀스마다 얼굴 클로즈업 배율 + 감정 필터 + 모션**을 바꿔 감정을 전달한다.

| 무드 | 연출 | 쓰이는 곳 |
|---|---|---|
| neutral / calm | 기본 · 부드럽게 | 평상시, 휴식 |
| focus | 살짝 줌 + 대비 | 훈련, PPV 주간, 경기 시작 |
| fierce | 클로즈업 + 강한 대비 | 대립 중, 경기 인트로, 기술 적중 |
| rage | 최대 클로즈업 + 채도↑ | 난입, 장외 난투, 세그먼트의 라이벌, 무효 경기 |
| pain | 탈채도 + 암부 | 부상, 기술을 받는 쪽 |
| down | 어둡고 차갑게 | 컨디션 한계, 패배 |
| joy | 밝고 채도↑ | 승리, 외부 활동 |
| proud | 또렷하고 밝게 | 챔피언, 니어폴 킥아웃, 프로모 |
| sepia | 세피아 | 은퇴 결산 |

경기 중에는 비트가 진행될 때마다 공격자/피격자의 표정이 실시간으로 전환된다(0.32초 트랜지션).
주간 리포트 상단에도 그 주 상황에 맞는 표정 컷이 붙는다.

> 표정 스트립(개당 30×26px)은 해상도가 부족해 원본을 그대로 쓰지 않았다.
> 게임 표시 크기(72~120px)로 올리면 이목구비가 뭉개져 현재 포트레이트보다 나빠진다.

## 주간 서술과 팁

- 매주 리포트 상단에 **전후 사정**이 붙는다 — PPV 임박, 부상, 대립 상대의 도발, 계약 만료 임박, 컨디션 한계, 부커의 신뢰 상승 등 현재 상태를 읽어 문장을 고른다
- 활동마다 **상황 묘사**가 따라붙고, 컨디션·부상·인지도·신뢰가 낮을 때는 별도의 문장으로 바뀐다
- 헤더의 **💡 버튼**은 현재 상태를 진단해 우선순위가 높은 조언 4개와 게임의 기본 원리를 보여준다

## 주간 사이클

활동 선택(훈련/휴식/프로모/백스테이지/외부활동) → 주 진행 → 활동 결과 → (대립 세그먼트) → (경기) → (랜덤 이벤트) → 정산(수입·인지도 감쇠·AI 로스터 변동·승격/재계약·자동 저장)

12주마다 PPV. 랭킹 2위 이내 + 인지도 조건 충족 시 PPV에서 타이틀 매치가 성립한다.

## 알려진 설계상 제약

- 태그팀/여러 단체 이적/스토리라인 분기는 범위 밖.
- AI 로스터는 인지도 드리프트와 타이틀 이동만 시뮬레이션한다(능력치 성장 없음).

## 캐릭터 아트

**65종 포트레이트**를 단일 WebP 아틀라스(11×6, 1320×960, 165KB)로 내장하고 `background-position`으로 잘라 쓴다.
외부 이미지 파일도 네트워크 요청도 없다(단일 HTML 284KB).

- **아틀라스 방식**: `data:` URI가 CSS 변수(`--atlas`)에 한 번만 들어가므로, 65칸 선택 그리드를 그려도 DOM에 이미지 데이터가 복제되지 않는다.
- **배경 처리**: 인물만 선명하게 남기고 바깥은 블러 + 암부화(피사계심도). 원본 배경의 제3자 상표·간판류는 판독 불가 수준으로 제거된다.
- **알파**: 타원 페더 마스크 + 하단 페이드 → 패널·링 어떤 배경 위에도 경계 없이 얹힌다.
- **톤 8종**: 원본 / 웜 / 쿨 / 앰버 / 시안 / 바이올렛 / 느와르 / 하이콘 (`filter`의 hue-rotate·saturate·contrast 조합)
- **프리셋 520가지** = 65 × 8. 생성 화면에서 그리드로 직접 고르거나 ◀ ▶ 로 전 조합을 순회할 수 있다.
- 로스터 18명은 65종 중 **중복 없이** 배정된다.

> 머리·헤어·몸통을 각각 교체하는 파츠 분리는 평면 일러스트에서는 불가능하다(렌더된 그림이라 레이어가 없다).
> 대신 헤어스타일·두상·복장이 모두 다른 캐릭터 65종으로 그 다양성을 커버한다.

UI 크롬(폰트, 하드 섀도, 게이지, 탭)은 레트로 도트 스타일을 유지한다.

## 밸런스 모델 (튜닝 지점)

- **경기 평점** `stars = (아군 경기력 0.62 + 상대 0.38) × 컨디션계수 + 대립열기 + PPV/타이틀 보정 ± 랜덤` / 3.8, 상한 ★5
- **인지도 증감** `(stars − 기대치) × 2.2`, 기대치 `= 1.8 + 인지도×0.018` → 톱스타일수록 명경기를 요구받는다(포화 방지)
- **부커 신뢰** `(stars − (1.9 + 푸시등급×0.32)) × 3.4`, 매주 50으로 3% 회귀
- **승패 확률** `sigmoid((내 푸시점수 − 상대 푸시점수)/15)`, 타이틀 도전 시 ×0.75
- **AI 로스터** 인지도는 초기값으로 평균 회귀(6%/주) — 전원 상한 수렴 방지
