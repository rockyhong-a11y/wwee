# RING QUEEN — 여자 프로레슬링 매니저

단일 HTML 파일 웹앱. 의존성·빌드·네트워크 요청 없음. `index.html`을 브라우저로 열면 바로 실행됩니다.
세로 화면 전용(아이폰 최적화, 권장 폭 390~430px), 도트 그래픽(canvas 픽셀 렌더링).

## 핵심 설계

- **커리어 모드**: 선수 1명(여성)의 데뷔 → GWF NEXT → 메인로스터 → 월드 챔피언 여정.
- **FM식 성장**: 능력치 6종 1~20 + **잠재치(PA) 상한**. 주 단위 훈련 XP 누적, 나이·컨디션에 따라 효율 변동, 31세부터 피지컬 노쇠.
- **조작 없음**: 경기는 자동 시뮬레이션 + 텍스트 로그. 플레이어 입력은 주간 활동 선택과 대립 세그먼트 선택뿐.
- **승패는 부커가 정한다**: 승패는 능력치가 아니라 푸시(인지도·신뢰·위상)로 결정되고, 능력치/컨디션은 **경기 평점(★)** 을 결정한다. 평점 → 인지도·신뢰 상승 → 푸시 상승 → 타이틀전. 이것이 게임의 메인 루프.

## 주간 사이클

활동 선택(훈련/휴식/프로모/백스테이지/외부활동) → 주 진행 → 활동 결과 → (대립 세그먼트) → (경기) → (랜덤 이벤트) → 정산(수입·인지도 감쇠·AI 로스터 변동·승격/재계약·자동 저장)

12주마다 PPV. 랭킹 2위 이내 + 인지도 조건 충족 시 PPV에서 타이틀 매치가 성립한다.

## QA 체크포인트

| 영역 | 확인 항목 |
|---|---|
| 진행 | 주 진행 후 모달 큐(활동→세그먼트→경기→이벤트)가 순서대로 소진되고 주차가 **정확히 1** 증가 |
| 경기 | 빨리감기 → `결과` 버튼 활성화, 결과 반영은 1회만(중복 적용 없음) |
| 성장 | 능력치가 잠재치를 초과하지 않음, 잠재치 도달 시 XP 손실 안내 |
| 부상 | 부상 중에는 활동이 강제 재활로 대체되고 경기 미배정, 주차 감소 |
| 타이틀 | 타이틀 매치 승패에 따라 벨트 보유자 이동, 이력(`커리어` 탭)에 기간 기록 |
| 저장 | 매주 자동 저장, 새로고침 후 `이어하기`로 주차/이름/스탯 복원 |
| 레이아웃 | 390px 폭에서 가로 스크롤 0, 하단 탭이 콘텐츠를 가리지 않음, 터치 타깃 ≥44px |

## 알려진 설계상 제약

- 태그팀/여러 단체 이적/스토리라인 분기는 범위 밖.
- AI 로스터는 인지도 드리프트와 타이틀 이동만 시뮬레이션한다(능력치 성장 없음).

## 밸런스 모델 (튜닝 지점)

- **경기 평점** `stars = (아군 경기력 0.62 + 상대 0.38) × 컨디션계수 + 대립열기 + PPV/타이틀 보정 ± 랜덤` / 3.8, 상한 ★5
- **인지도 증감** `(stars − 기대치) × 2.2`, 기대치 `= 1.8 + 인지도×0.018` → 톱스타일수록 명경기를 요구받는다(포화 방지)
- **부커 신뢰** `(stars − (1.9 + 푸시등급×0.32)) × 3.4`, 매주 50으로 3% 회귀
- **승패 확률** `sigmoid((내 푸시점수 − 상대 푸시점수)/15)`, 타이틀 도전 시 ×0.75
- **AI 로스터** 인지도는 초기값으로 평균 회귀(6%/주) — 전원 상한 수렴 방지
